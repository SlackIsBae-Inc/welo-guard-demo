# Welo Guard

Marketing homepage for Welo Guard — AI-powered enterprise security platform.

## Getting Started

```sh
git clone <repo-url>
cd weloguard
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Development

This is a static site — just HTML and CSS. To start a local dev server:

```sh
npm run dev
```

Format code:

```sh
npm run format
```

## Deploy

Deploy to any static hosting provider (Vercel, Netlify, Cloudflare Pages, S3 + CloudFront). Point the root to the repo directory — no build step required.
